# Michael Edwin Panama: Portfolio

Personal portfolio of Michael Edwin Panama, AI Data Annotation and Model Evaluation Specialist.

Live site: https://eazyvibez25-ux.github.io

Plain HTML, CSS and JavaScript, blue-and-white design. Every file sits in one folder (no subfolders), so the whole site can be uploaded from a phone in one go.

## Set up a fresh repository (from a phone)

1. Extract the zip in your phone's Files app. You get one folder with **20 files**.
2. On GitHub, create a new repository named exactly **`eazyvibez25-ux.github.io`**. Make it **Public** and leave "Add a README" unticked.
3. On the new repository's page, tap **uploading an existing file**.
4. Tap **choose your files**, open the extracted folder, select **all 20 files**, and confirm.
5. Wait until every file shows in the list, then tap **Commit changes**.
6. Open **Settings → Pages**. Set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, then **Save**.
7. After two or three minutes, open https://eazyvibez25-ux.github.io in a private tab.

## Updating it later

Upload the changed file with the **same name** and commit; it replaces the old one.

| To change | Replace this file |
| --- | --- |
| Any text on the main page | `index.html` |
| The SmartEduTrack case study | `smartedutrack.html` |
| The CV people download | `Michael-Edwin-Panama-CV.pdf` |
| Photos | `michael-portrait.jpg` (hero), `michael-avatar.jpg` (round photo) |
| Colours and layout | `style.css` (colours are listed at the top) |
